# Playtest scenes

Every scene Greg should open and try lives here, at the top level of this folder.
Open one, press Play, and leave a verdict on the matching Quest Board card.

| Scene | What to try | Board card |
|---|---|---|
| `TerrainSandbox.unity` | Walk, sprint (Shift), dive; look at region blending, water, snow, sky. F11 cycles hero presets. | RLC-035 |

`Archive/` holds retired scenes kept for reference. Nothing in there needs review.

## Rules (for Claude sessions)

- A new scene that needs Greg's eyes goes at the top level of this folder, and gets a row in the table above.
- When a playtest is done (verdict given) or its system is retired, move the scene to `Archive/`, or delete it if it has no reference value. Keep the table current.
- Scene builders (`Relic/<Stream>/Build ...` menu items) write straight to these paths.
- `Archive/WritingDesk.unity`: the v1 glyph-drawing spell desk, retired 2026-11-18 when spells became programs (doc 22).
